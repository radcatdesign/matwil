# Matt Wilhelmsen homepage redesign

Homepage redesign concept for [mattwil.com](https://www.mattwil.com/) by RADCAT.

`index.html` is a single self-contained page. Open it in a browser, or turn on GitHub Pages for this repo to get a shareable link.

## Notes

- Photos and the logo load directly from mattwil.com. Download them into the project before a production build.
- Links point to the live mattwil.com pages.
- Copy is drafted for review and needs Matt's sign-off, especially the service descriptions.
- Type: Archivo and Source Serif 4 from Google Fonts. Brand colors come from the existing logo.
